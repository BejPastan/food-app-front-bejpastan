# Components Directory

This directory contains all reusable UI components for the food app PWA, organized by category.

## Directory Map

```
src/components/
├── Basic/              # Core UI building blocks (text, inputs, buttons, loading)
├── Forms/              # Form wrappers, form fields, and form-specific components
├── Navigation/         # Navigation bar and navigation items
├── PageComponents/     # Page-level layout components (headers, modals)
├── Tiles/              # Data display tiles (food, meal, recipe, unit, user meal)
├── TabContainer.vue    # Main layout wrapper (header + content + bottom nav)
```
